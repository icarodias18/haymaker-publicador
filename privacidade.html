Política de privacidade – HayMaker Publicador

Atualizada em 19 de novembro de 2026.

Quem usa

O HayMaker Publicador é uma ferramenta interna, usada apenas pelos donos dos canais de YouTube Guerra Desenhada e Decision Battles para gerenciar os próprios canais. Não há usuários externos.

Que dados acessa

Com a autorização do dono de cada canal, pela API do YouTube: dados do próprio canal e dos próprios vídeos (títulos, descrições, legendas, playlists, status de publicação) e as estatísticas desses vídeos (YouTube Analytics). A ferramenta não acessa dados de espectadores além dos números agregados que o YouTube Analytics fornece.

Como usa e guarda

Os dados são usados só para publicar e organizar os vídeos dos próprios canais e para acompanhar o desempenho deles. Ficam guardados de forma privada pelos donos, não são vendidos, não são compartilhados com terceiros e não são usados para publicidade. O uso segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado, e os Termos de Serviço da API do YouTube.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Dados guardados a partir da API são apagados quando deixam de ser necessários. A Política de Privacidade do Google está em policies.google.com/privacy.

Privacy policy – HayMaker Publicador

Updated November 19, 2026.

Who uses it. HayMaker Publicador is an internal tool used only by the owners of the YouTube channels Guerra Desenhada and Decision Battles to manage their own channels. There are no external users.

What data it accesses. With each channel owner's authorization, through the YouTube API: data about the owner's own channel and videos (titles, descriptions, captions, playlists, publishing status) and the analytics of those videos (YouTube Analytics). It does not access viewer data beyond the aggregate figures YouTube Analytics provides.

How it is used and stored. Data is used only to publish and organize the owners' own videos and to track their performance. It is stored privately by the owners, is not sold, not shared with third parties, and not used for advertising. Use complies with the Google API Services User Data Policy, including the Limited Use requirements, and the YouTube API Services Terms of Service.

How to revoke. Access can be revoked at any time at myaccount.google.com/permissions. Data stored from the API is deleted when no longer needed. Google's Privacy Policy: policies.google.com/privacy.

Contact. Through the channels' YouTube pages.
